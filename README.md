# Estudos de Programação

Repositório pessoal de atividades acadêmicas e exercícios práticos desenvolvidos ao longo dos meus estudos de programação.

## Conteúdo

Atualmente, o repositório reúne exercícios e projetos práticos em **C#**, organizados por etapa de aprendizagem:

- fundamentos da linguagem e entrada/saída de dados;
- operadores, estruturas condicionais e estruturas de repetição;
- vetores e matrizes;
- métodos, parâmetros e decomposição de problemas;
- manipulação de strings e dados em formato CSV.
- projetos de console que combinam diferentes conceitos da linguagem.

## Organização

```text
csharp/

│   └── lista-08/
└── projetos/

```

Cada arquivo `.cs` representa um exercício independente ou um projeto prático. Consulte o [guia da seção de C#](csharp/README.md) para ver os temas de cada lista, os projetos e as orientações de execução.

## Objetivo

Registrar minha evolução, manter as atividades bem organizadas e facilitar a consulta aos conceitos praticados durante a formação.
